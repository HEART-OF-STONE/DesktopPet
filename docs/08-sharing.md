# 桌边 v0.8.0：运行与分享

本文对应开发源码；版本尚未完成全部发布验收。正式安装包与校验清单只从
[项目 Releases](https://github.com/HEART-OF-STONE/DesktopPet/releases) 获取。

## 自动换边、独立缩放与全屏避让

打开「偏好设置 → 桌面上的样子」：

- **侧边数据框位置**：默认自动，靠右时移到角色左侧，靠左时移到右侧；也可固定左侧或右侧。中间区域保持当前方向，避免来回切换。换边本身不改变角色位置，固定方向时仍遵守可见边界。
- **数据框大小**：80%–125%，默认 100%，滑动立即生效，支持恢复默认。只缩放常显框，角色大小独立；可用空间不足时仍会限制显示尺寸。展开详情保留正常字号并限制在工作区内。
- **全屏时自动避让**：默认开启。桌宠所在屏幕的前台应用覆盖整个屏幕且没有普通窗口标题栏时，临时隐藏角色、数据框和气泡，退出全屏或切换到普通应用后恢复。普通最大化窗口不触发。检测约每 0.5 秒一次，完全本地，不调用模型；后台用量与任务采集继续。

全屏避让不修改「显示宠物」偏好，因此不会将手动隐藏的桌宠擅自显示。以上设置会保存，并随偏好备份恢复。实体游戏独占全屏、不同 DPI 多屏和锁屏 / 休眠场景仍需继续实机验收。

## 贴边与拖动

允许透明窗口留白越过桌面边缘，按角色与常显数据框的可见范围放置，边缘保留约 6 个逻辑像素。固定在某侧的数据框仍占据该侧宽度，自动模式可以换到另一侧。拖动时按方向倾斜，松手立即开始回正，约 0.22 秒结束拖动动作；对话气泡可以继续显示。贴边后的气泡和详情会限制在当前屏幕工作区内。

## 切换数据框形态

在「偏好设置 → 桌面上的样子 → 数据框样式」选择后立即生效，重启会保留选择：

- **侧边卡片**：宠物左侧或右侧常显完整数据，周 / 5h 并排。
- **底部双行底座**：宠物上、数据框下；金额和 Token 并排，周 / 5h 各用一条独立横向进度条，只有一个额度窗口时自动收紧。
- **简洁状态条**：显示任务状态和所选附加指标，占用空间最小；点击展开详情。

v0.7.6 将底部卡片收窄，金额与 Token 等宽对齐，去掉金额前的“≈”；“今日预估”标签继续表明它是估算值。底部样式沿用现有角色素材；窗口空间不足时自动限制角色尺寸。超大金额使用万 / 亿缩写，悬停看完整金额，精确预估及计价说明仍在详情中。「Agent 看板 → 连接与提醒 → 桌宠常显样式」也能选择上述三种样式，该入口需点击保存连接设置。

v0.7.3 默认隐藏角色底部控制条，鼠标移到原位置时显示。气泡跟随角色头顶，可在「偏好设置 → 桌面上的样子」调整水平 / 垂直位置、显示气泡预览或恢复默认。向左、向右拖动时角色会随方向倾斜，松手后短暂保留动作再恢复。

v0.7.4 加入自动额度查询：开启 Codex 采集时，主额度超过 10 分钟未更新或已到重置时间，会自动查询；实际请求至少间隔 10 分钟。有新鲜主额度日志时延后请求，Spark 日志不会替代主额度的新鲜度。启动时没有记录或记录已旧，会自动尝试一次。

连续失败后按 10 / 20 / 40 / 60 分钟退避，最长每小时重试一次，成功后恢复正常间隔。手动查询与自动查询共享冷却，重启不清除冷却；暂停 Codex 采集则停止查询。详情与看板显示下次检查时间、上次尝试和失败原因。需要 Codex CLI 已有可用登录态，失败时保留上次真实数值。

额度“待更新”表示快照超过 15 分钟、已到重置时间、缺少时间或采集暂停；悬停提示和展开详情可查看原因。后台仍每 10 秒读取本地日志，日志读取和实时额度查询是两个不同频率。额度查询只读取账户限制，不创建模型任务。

## 侧边常显数据签

v0.7.1 调整了侧边卡片与角色的比例、标题和标签字号、边框与留白，使整体更接近侧边设计稿。侧边样式的角色基准显示尺寸稍大，简洁状态条仍沿用原来的尺寸；已有大小偏好继续生效，窄视口会自动限制显示大小。

默认自动选择宠物侧边显示任务状态、Codex 主额度、今日美元预估与今日 Token。周额度在左，5h 额度在右，两项之间用竖线分隔，各有独立短进度条；只有一项时自动占满一行。未返回主额度时显示暂无数据，不用 Spark 替代主额度。

点击标题或数据区打开完整详情，查看 Spark、更新时间和更精确的预估金额。常显金额保留两位小数，正数不足一美分显示 `<$0.01`；v0.7.2 将“部分计价”说明放在展开详情，侧边仍保留未计价、采集异常和过期额度提示。预估金额与 Token 合计沿用看板统计范围，不是单一任务费用。

“Agent 看板 → 连接与提醒 → 桌宠常显样式”可切换“侧边数据签”和旧版“简洁状态条”，点击“保存连接设置”后生效。“状态条附加指标”仅影响简洁状态条。关闭“显示桌宠任务与用量”可隐藏整块数据区。

角色仍支持原来的点击和拖动，数据区点击用于查看详情。窗口为两侧排布预留透明空间；角色放大时面板字号不跟随放大，数据框大小单独调整，系统 DPI 缩放仍正常应用。边界按可见内容计算；需要重新停靠时可从托盘选择“移回主屏”。

## Codex 额度显示修复

主额度优先显示。账户返回 5 小时和 7 天窗口时，两项都会出现在看板与桌宠详情；选择“Codex 额度”状态条指标时，也会同时显示两个主窗口。按实际数据适配套餐，不凭 Plus / Pro 名称补出未返回的额度。

Spark 显示为 `GPT-5.3-Codex-Spark`，与主额度分开保存。各类日志更新不再互相覆盖，各项显示自己的观察时间；超过 15 分钟或已到重置时间的旧数值标记“待更新”，不会自行推算为 100%。桌宠详情可滚动查看全部窗口。

升级后沿用已有快照；之前已被覆盖的类别需要等到该类下一条日志更新，或在看板点击“查询实时额度”取得数据。实时查询仍使用本机 Codex CLI 的登录状态。

保留高 DPI 显示：内置静态和逐帧素材每帧为 768×768，显示大小不变；绘制分辨率自动跟随系统像素密度和宠物大小。已有自定义低分辨率图片不会凭空增加细节，可换用更高清的素材。

## 美元费用预估

打开“Agent 看板 → 美元费用预估”，查看今日、近 7 天与各来源/模型的预估金额。侧边数据签默认常显今日预估；使用简洁状态条时，在“连接与提醒 → 状态条附加指标”选择“今日美元预估”，再保存连接设置。

展开“配置模型单价”可新增或修改来源、模型 ID、普通输入、缓存输入与输出的 USD / 百万 token 单价。来源和模型 ID 必须与日志一致；保存后按当前价格重新估算全部保留记录。空单价不等于免费；免费需明确填写 0。“未计价”表示缺少价格或明细，“部分”表示小计未包含全部记录。历史补读中或采集出错时也会提示。

预估是本地算术，不调用模型、不额外读取日志，也不请求账单。初始参考价覆盖 Codex 来源的 GPT-6 Astra、GPT-5.6 Sol/Terra/Luna，按标准短上下文价格，核对日期 2026-09-15。日志未区分长上下文、速度档位与缓存写入费用，工具、图像、语音等额外费用未计入；可自行调整假设单价。价格不自动联网更新。预估不代表 Pro 实际扣款、订阅剩余额度或账户余额。

单价存放于本机联动数据；角色/偏好备份不包含此设置。

## 直接运行

1. 运行发布的安装包，或将免安装 ZIP 完整解压到自己的文件夹。
2. 从托盘退出已运行的旧版桌边，再双击 `DesktopPet.exe`。
3. 打开左侧“Agent 看板”，在最上方“联动演示”中点选工作中、待确认、完成、失败或低余额。

程序面向 Windows x64，需要 Microsoft Edge WebView2 Runtime。不需要 Node.js、Rust 或编译环境。安装包只为当前 Windows 用户安装，缺少 WebView2 时会尝试联网安装运行时。本版未签名，尚未完成干净系统验收。

## 提醒收件箱

左侧“提醒收件箱”保存已开启的 Agent 完成、失败、待确认及余额提醒，显示来源、时间与已读状态。可筛选未读、全部或需处理，也可全部已读、清理已读。最多保留最近 90 天的 300 条。

免打扰只抑制气泡和声音，提醒仍会进入收件箱；在 Agent 看板关闭某类提醒后，该类新提醒不会记录。首次补读历史日志、联动演示与通道自检不会灌入历史提醒。桌宠状态详情中的“未读提醒”可直接打开收件箱；计时提醒仍沿用桌宠原有提示，不进入 Agent 收件箱。

## 备份与换机恢复

在“偏好设置 → 备份与恢复”选择“导出完整备份”，妥善保存生成的 JSON。备份包含导入角色的 PNG、皮肤、昵称、自定义默认名和偏好；不包含 API Key、Agent 记录、收件箱、余额、计时、开机启动和更新来源。

在另一台电脑选择该备份文件（最大 32 MB），核对时间和角色列表，再确认恢复。恢复会替换现有导入角色与偏好；当前计时及联动数据保留。系统会自动创建一个本机还原点，“撤销上次恢复”可回到恢复前的角色与偏好，退出重开后仍可撤销。新一次恢复会覆盖上一次还原点。

备份文件不是角色包，请从偏好设置恢复。旧版“导出设置”只含偏好，不能作为完整备份导入。换机后需要自行重新连接 Agent 或填写自己的账户密钥。

## 安装、开机启动与更新

- 推荐将安装版用于长期使用；免安装版也可开启自启动，但不要随意移动程序文件夹。
- “偏好设置 → 启动与更新”可打开“登录 Windows 时启动”。登录后只显示桌宠并驻留托盘，管理面板不会主动弹出；隐藏宠物的偏好仍然有效。
- 免安装程序移动后，如果提示启动项指向旧位置，点击“更新启动位置”。安装包升级会保留已有自启动选择并更新路径。
- 更新检查默认未配置，不会主动联网。在“更新来源”填写发布者提供的公开 GitHub `所有者/仓库名`，再手动检查。无需访问令牌；检查间隔至少一分钟。只有稳定版本 `v主版本.次版本.修订号` 会参与比较。
- 有新版本时显示发布说明并提供“打开发布页”。当前不自动下载或安装；导出备份、退出旧版后再安装新版。尚未接入本项目正式仓库和真实公开版本。
- 安装版可通过 Windows 已安装的应用卸载。默认保留用户数据；仅在卸载界面明确选择删除数据时才清理。卸载会移除仍指向本安装目录的自启动项。
- 免安装版删除前，请先关闭开机启动并从托盘退出。程序文件与用户数据分别保存；删除解压目录不会删除 `%APPDATA%\com.desktop-pet.companion`。

## 自主陪伴

在“偏好设置 → 自主陪伴”开启或关闭活动，可选安静（90–180 秒）、适中（45–90 秒）、活泼（20–40 秒）三档冷却。默认原地陪伴，可选左右 8 或 18 像素的小范围挪动；范围以当前位置为中心，限于桌宠窗口内，不会自行跨屏。

提供伸懒腰、四处看看、打盹和挪一挪的即时预览，可同步到桌宠并随时停止。自主行为不主动发声、不调用 AI、不连续重复；拖动、互动、计时提醒和 Agent 反馈优先。免打扰、隐藏或休眠恢复后重新等待，不补播过期动作。

## 联动接入助手

打开“Agent 看板 → 联动接入助手”：

1. 检查 Codex 日志是否可读；“重新检查日志”只检查本机，不查询余额或启动模型。错误时按提示修改看板底部的数据目录。
2. 开启事件接口，点击“测试本机通道”。测试经过实际本机接口和鉴权，再播放一次演示，不改变真实任务或用量。
3. 按下方接入步骤配置 Agent，触发一次实际事件。只有收到外部事件才显示相应来源；本机自检成功不代表 Hook 已安装。最近事件和自检结果仅记录本次启动，不作为持续在线证明。

可复制 PowerShell 手动测试命令：它会创建一条 `manual-test` 任务，不计 token。若提示缺少接入脚本，请确认完整解压了发布 ZIP。

## 新增的桌宠界面

- 名字下方常驻任务状态，点击可展开用量详情，并跳转完整看板。
- 在“Agent 看板 → 连接与提醒”可关闭状态条，或增加今日 token、Codex 额度、DeepSeek 余额中的一项。保存后立即同步到桌面窗口。
- 工作中：轻微左右思考；待确认：轻跳摇摆；完成：庆祝；失败：短暂摇头后低头。静态图通过程序变形表现，逐帧角色沿用现有动作帧并叠加变形，不需要重做旧角色包。
- 多任务优先展示待确认，再是近期失败、运行中、刚完成。超过 30 分钟没有更新的运行状态会标为待核实。
- 演示为临时显示，持续 10 秒，可停止。它不发送 Agent 请求，不产生 token，不改变真实任务、余额或用量；真实提醒会打断演示。免打扰时保留状态文字，暂停联动动作、气泡和音效。
- 拖动、摸头和计时提醒优先于 Agent 动作。额度明确标注快照或更新时间，尚未读取的值不会显示为零。

## 日志读取是否消耗 token？

不会。当前程序由本地代码读取日志，计算数值，没有把日志发给模型。

| 操作 | 模型 token | 网络行为 |
|---|---|---|
| 每 10 秒检查本地 Codex 日志 | 不消耗 | 不联网 |
| 状态条、动画、展开详情、联动演示 | 不消耗 | 不请求外部服务 |
| DeepSeek 自动余额查询 | 不进行模型推理 | 配置密钥并启用后，每约 60 秒请求余额接口 |
| 手动查询 Codex 实时额度 | 不启动模型任务 | 通过本机 CLI 请求账户额度，可能需要联网和认证 |

网络查询仍可能遇到服务端限流或错误，不能保证任何频率都不会限流。不要连续点击刷新。未来如果增加 AI 聊天或让模型分析日志，那部分才需要另行统计模型调用与费用。

本地轮询仍有磁盘和 CPU 开销。历史补读每轮总计约 64 MB、单文件约 32 MB；有大量历史时逐批处理并显示未完成标记。没有新记录时不反复写入整个账本。长期 CPU / 内存和超大历史目录完整补读仍需进一步验收。

## 分享给别人

发送本版本的安装包或免安装 ZIP 即可，旁边的 SHA-256 清单可用于核对文件完整性。发布包仅包含程序、接入脚本与说明，不包含你的配置、任务日志、余额历史或凭据。未签名文件的校验和不能替代发布者身份验证。

包内三份说明：`START-HERE.md`、`AGENT-GUIDE.md`、`CHARACTER-GUIDE.md`；同时保留 `LICENSE`、`THIRD_PARTY_NOTICES.md`、`THIRD_PARTY_LICENSES.txt` 和 `DeepSeek-Balance-Whale-Widget-MIT.txt`。无需把这些说明导入角色衣橱；角色导入只接收 PNG 与角色 JSON。开发 Todo、设计稿与测试记录不会进入发布包。

接收者首次运行时使用自己的 Windows 用户数据目录。Codex 用户可以使用自动检测的本机日志目录；需要 DeepSeek 余额的人在应用内保存自己的 API Key。不使用 Codex 的人仍可使用陪伴、角色、计时和联动演示。

不要将 `%APPDATA%\com.desktop-pet.companion`、`.codex`、`agent-bridge.json` 或自己的工作区缓存一起分享。角色包可另行分享，但应确认有权分发其美术素材。

其它 Agent 需要按 `AGENT-GUIDE.md` 接入。Codex 插件封装尚属后续选项，本版不要求安装插件。
