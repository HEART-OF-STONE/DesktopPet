# DesktopPet v0.9.5

修复 GPT-6 Luna / Sol 用量有 Token、但美元预估显示“未计价”的问题。

- 补充 GPT-6 Luna 与 GPT-6 Sol 的标准短上下文参考价格。
- 已有用户首次启动新版时自动补入缺失的两项价格，保留自定义价格；已保留的历史 Token 记录立即参与重新估算，无需重读日志。此次补入后手动移除的价格不会在重启时重新添加。
- 缺价改为明确显示“缺少单价”，详情列出未匹配的模型；Token 明细不完整单独提示。
- 未确认价格的内部标识（如 codex-auto-review）继续显示缺价，不推测实际模型，不伪造金额。

参考价格（美元 / 百万 Token，输入 / 缓存输入 / 输出）：[GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) 为 0.10 / 0.01 / 0.50；[GPT-6 Sol](https://developers.openai.com/api/docs/models/gpt-6-sol) 为 2 / 0.20 / 10，核对于 2026-09-29。金额是本地参考估算，不是订阅账单；暂不区分长上下文、速度档位和额外工具费用。

可通过“偏好设置 → 启动与更新”更新。沿用当前安装目录并保留角色与偏好。
