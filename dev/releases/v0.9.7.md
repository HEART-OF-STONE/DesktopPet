# DesktopPet v0.9.7

本版丰富啾咪的动画和回应，改善吃零食的姿态，并为自定义人物、动作和素材更新补齐基础能力。

## 人物与动作

- 内置动画版提供 16 种状态，增加伸懒腰、四处看看、打瞌睡、挪一挪、认真工作、抬头提醒、有点困惑，以及眨眼、动耳朵和摆尾巴。摸头、吃零食、庆祝等动作有不同回应。
- 保留圆润连贯的头部和耳朵轮廓；吃零食时用短圆的小爪子托住零食送到嘴边，咀嚼时位置同步。
- 动耳朵随机间隔 11–23 秒、摆尾巴 8–18 秒，在待机或认真工作时依次触发；免打扰时停止。间隔独立于“自主动作频率”设置。
- 自主动作结合最近播放记录、冷却时间与权重选择，减少重复；播放完成后自然回到待机。
- “我的伙伴”和“角色衣橱”增加独立动作试映，可逐个查看动作和回应，再选择让角色来陪伴。

## 自定义角色

- v2 角色包支持扩展动作、最多四个额外变体、循环时长和自主动作权重 / 冷却参数；继续支持 v1 角色包。
- 已导入角色可点击“更新素材”，重新选择新版 JSON 与 PNG；保留角色身份、昵称、默认名字、衣橱顺序和仍然存在的皮肤。更新失败保留原素材。
- 仓库提供更清晰的完整动作示例 `examples/motion-pack-v2`；待机使用 512 像素帧，其它动作使用 256 像素帧，在体积限制内保留完整动作和原有时长。
- 导入、备份恢复和素材更新共用完整校验，检查变体、图片区域与资源限制。

## 安装与更新

- 提供 Windows x64 安装包和便携 ZIP、SHA-256 清单与更新签名；已安装版可通过“偏好设置 → 启动与更新”检查、下载并验证签名后安装。
- 自定义角色保留原素材，需要新版示例时请使用“更新素材”。本版延续 v0.9.6 的计价与额度功能，不含其它仍在开发的任务。
