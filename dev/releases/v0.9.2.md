# DesktopPet v0.9.2

Codex 积分余额与美元折合、近期优先读取，以及更紧凑的桌宠用量详情。

## 相对 v0.9.1

- 内置伙伴默认名改为「啾咪」，保留已有昵称、自定义默认名和稳定角色 ID。
- 桌宠点击展开的小详情与 Agent 看板增加 Codex 积分余额；常显默认关闭，可通过勾选添加一行。
- 积分支持美元折合 / 原始积分切换。详情同时展示两者；默认参考 $0.04 / credit，可修改比例。积分原值、订阅额度百分比与今日费用预估分别统计。
- 小详情将积分与美元折合放在同一行，加“积分”单位并用 = 连接；换算说明与较旧的附加额度默认收起，主额度始终直接显示。
- 首次启动优先取得最新额度、积分和任务状态，默认补齐近 7 个本地自然日；旧但仍在使用的会话也参与近期统计。累计值基线用于防止把旧用量算进今天。
- 看板显示近期文件补读进度。更早历史改为按需开启、可暂停，保存独立进度；不再让全部历史扫描阻塞近期完成状态。
- 本地补读短批次推进，完成后恢复原轮询间隔；远端额度和余额请求维持各自限频，无模型调用。

## 使用方式

1. 首次启动能先看到积分 / 周额度，近期补齐后黄色提示消失。
2. 点击桌宠数据框查看原始积分与美元折合；常显默认不新增行。
3. 勾选常显后，侧边 / 底部布局正常；单位切换、比例修改与重启保存正常。
4. 开启 / 暂停更早历史不影响近期状态；重启不会重复累计用量。

已有支持签名更新的版本可在“偏好设置 → 启动与更新”检查、下载并安装。也可下载安装包或便携 ZIP；更新签名和 SHA-256 清单随附件提供。

更新保留已有昵称与偏好。美元折合为按设定比例计算的参考价值，非现金余额；不会从积分中扣除今日费用预估。
