# DesktopPet v0.9.4

托盘菜单更清楚，显示状态与操作保持同步。

- 第一项根据设置切换为“显示宠物”或“隐藏宠物”。隐藏宠物时一并隐藏数据框和气泡，后台统计继续。
- “免打扰”使用勾选显示开启状态，设置页与托盘同步；保留计时提醒。
- “找回宠物”恢复主屏位置并开启显示，保留角色、大小及全屏避让设置。
- “打开管理面板”和“退出桌边”使用分隔线与宠物控制分组。
- 左键单击托盘图标打开管理面板，右键打开菜单。
- 悬停提示跟随角色名称、隐藏及免打扰状态；全屏避让时增加不可点击的原因说明。
- 改名、设置修改、宠物控制条操作及备份恢复均同步到托盘；仅状态变化时更新菜单。

已有版本可在“偏好设置 → 启动与更新”检查、下载并安装，也可使用本页安装包。v0.9.3 发起更新会沿用当前程序目录，首次安装仍可自行选择目录；升级保留已有角色与偏好。

附件提供签名安装包、签名文件、便携 ZIP、SHA-256 清单和在线更新清单。更新签名不等同于 Windows Authenticode 签名，Windows 仍可能显示未知发布者。
