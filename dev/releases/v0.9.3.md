# DesktopPet v0.9.3

更新沿用当前程序目录，并修复桌宠的任务状态显示。

## 安装与更新

- 首次安装保留完整向导：提供默认目录，可选择 D / E 盘等有写入权限的文件夹。
- 应用内更新明确使用当前程序所在目录，避免过期的安装路径记录使更新落到其他位置。支持中文及带空格目录。
- “偏好设置 → 启动与更新”新增程序位置，方便确认后续更新目的地。
- 手动重新运行安装包会读取上次选择的目录。免安装版从本版本发起应用内更新时，在原目录转为安装版，之后从新快捷方式启动。

## 任务状态

- 三种常显布局统一颜色：工作中蓝色、完成绿色、待确认橙色、出错红色，空闲 / 待核实 / 中断灰色。
- 同一 Codex 会话只用最新轮次决定当前状态及活跃任务数，防止已被后续轮次替代的旧任务一直显示“待核实”。历史记录保留，不同会话和其他 Agent 的并行任务仍分别统计。

## 换盘与升级

已装在 C 盘且想换盘：退出桌宠，卸载时**不要勾选删除用户数据**，再运行本版安装包并选择目标目录。更改安装位置不会自动迁移独立保存的用户数据；角色和偏好继续保留。不要直接剪切已安装的程序目录。

升级不会自动搬迁已有安装。v0.9.2 及更早版本发起更新时，仍使用旧版的安装路径处理；本版安装完成后，后续应用内更新才使用新增的目录绑定逻辑。

可在已有版本中检查、下载并安装更新，或使用本页安装包。附件提供更新签名、便携 ZIP 与 SHA-256 校验清单。更新签名不等同于 Windows Authenticode 签名，Windows 仍可能显示未知发布者。
