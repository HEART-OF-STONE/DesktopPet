## v0.5.1：高 DPI 清晰度（2026-09-15）

- 根因：绘制缓冲固定为逻辑画布 256×256，内置 PNG 每帧同样只有 256×256，系统缩放与宠物放大时产生两次低分辨率放大。
- 内置原创 SVG 源重新栅格化为每帧 768×768；精灵图改用 4 列 × 3 行，逻辑画布仍为 256×256。PNG 序列和精灵图导入示例同步更新，角色 ID、名称和用户偏好不变。
- Canvas 缓冲按显示尺寸乘以像素密度取整，保持逻辑坐标与透明命中网格；上限 4 倍密度 / 最长边 2048，避免无界分配。监听缩放变化，并在桌宠已有绘制循环中检测未触发通知的 DPR 变化。
- 原生测试发现 WebView2 可返回 `1.0000000447` 一类浮点 DPR，且 CDP 改密度时不一定通知媒体查询。分别以就近取整与绘制循环检测修正。
- 前端 18 项测试、TypeScript 与生产构建通过。`scripts/test-hidpi.ps1` 用隔离原生窗口模拟 100% / 150% / 200% / 300%：两类角色缓冲分别为 256 / 384 / 512 / 768，逻辑宽度始终 256；放大到 130% 及回切密度均通过，窗口边界保持。
- 已检查 `output/playwright/hidpi-doubao-static.png` 和 `hidpi-doubao-sprite.png`。这覆盖原生 WebView 的密度仿真，不等于实际跨物理显示器、Win32 鼠标穿透和全部系统矩阵已验收。
- 原有 P0 原生回归通过：四种动作同步、最大缩放边界、自动调度、免打扰/隐藏/互动/Agent 打断以及完整重启。发布脚本生成 v0.5.1 安装包、六文件免安装 ZIP 与 SHA-256 清单。

自定义低分辨率素材仍受原图细节限制。内置素材尺寸提升会增加图片解码内存；长期内存验收保持待办，不将其标成已完成。
